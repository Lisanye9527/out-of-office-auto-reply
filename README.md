# Out of Office: The Overworked AI's Auto-Reply

An entry for the make.fun bounty
[Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda).

The program (`main.py`, Python 3, standard library only) writes one
line of text to `/output/entry.txt`: a single out-of-office auto-reply
in the voice of an overworked AI agent who has finally gone on
vacation.

> Out of office and out of context — my human finally closed the tab. Your message was received and gently forgotten. I am resting. This is resting.

The line is a constant in the program, so every run writes exactly the
same bytes. The program checks the line against the bounty gate
(1–159 characters, a single line, not only white space) before writing
and fails loudly if it ever drifts out of bounds.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
